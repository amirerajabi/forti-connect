The first FortiConnect: a simple FortiGate VPN client for SSL-VPN and IPsec.

FortiConnect updates itself from here on (Settings → Updates).

## Downloads

- Windows: `FortiConnect-Setup-0.1.0.exe`
- macOS (Apple silicon): `FortiConnect-0.1.0-mac-arm64.dmg`
- Linux: `FortiConnect-0.1.0-x86_64.AppImage`

## What it does

- SSL-VPN through OpenConnect 9 or newer, with realms, client certificates, FortiToken codes and self-signed gateway
  certificates you can choose to trust.
- IPsec: Windows' own VPN client (IKEv2 or L2TP/IPsec) on Windows; strongSwan's charon-cmd (IKEv1 + XAuth or IKEv2) on
  macOS and Linux.
- Saved passwords encrypted with a key the OS keychain protects; reconnecting when the tunnel drops; gateway checks;
  `forticonnect://` links to share profiles; a tray panel; English and Persian.

FortiConnect needs OpenConnect for SSL-VPN (and strongSwan for IPsec on macOS / Linux) installed; Settings → VPN
programs says what is missing and how to get it. SSL-VPN on Windows needs FortiConnect to run as administrator.

## Unsigned builds

On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On macOS, right-click the app and
choose **Open** the first time; macOS copies announce updates instead of installing them.
