Long IPsec connections stay up: FortiConnect now renews the IPsec and IKE keys during a connection, so the tunnel no
longer drops after about 12 hours.

FortiConnect 0.5.x updates itself to this version (Settings → Updates).

## Downloads

- Windows: `FortiConnect-Setup-0.5.3.exe` (includes OpenConnect)
- macOS (Apple silicon): `FortiConnect-0.5.3-mac-arm64.dmg`
- Linux: `FortiConnect-0.5.3-x86_64.AppImage`

## New

- **IPsec keys are renewed while connected.** When the FortiGate renews the keys (phase 2 every 43200 s, phase 1 every
  86400 s by default), FortiConnect takes the new ones instead of refusing them. If the FortiGate does not renew them
  first, FortiConnect does it itself a few minutes before they run out, with the same Diffie-Hellman group (PFS).
- No packets are lost during the switch: the old and new keys both work for a moment.

The log says "renewed the IPsec keys" when it happens. FortiConnect's renewal is tested against a test gateway; a
renewal with a real FortiGate happens only after about 12 hours of connection.

## Unsigned builds

On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On macOS, right-click the app and
choose **Open** the first time; macOS copies announce updates instead of installing them.
