OpenConnect now comes with FortiConnect on Windows, and the traffic numbers work.

FortiConnect 0.2.x updates itself to this version (Settings → Updates).

## Downloads

- Windows: `FortiConnect-Setup-0.3.0.exe` (includes OpenConnect)
- macOS (Apple silicon): `FortiConnect-0.3.0-mac-arm64.dmg`
- Linux: `FortiConnect-0.3.0-x86_64.AppImage`

## New

- **Nothing to install on Windows.** The installer includes OpenConnect (the OpenConnect project's own Windows build,
  version 9.21), and FortiConnect uses it automatically.
- **The VPN helper installs itself.** The first time you connect with SSL-VPN, FortiConnect sets up its VPN helper:
  Windows asks for administrator rights once, and the connection carries on. A newer helper that comes with an update
  installs the same way. The helper keeps its own copy of OpenConnect where only administrators can change it.

## Fixes

- **Download and upload no longer stay at 0 B/s** while connected on Windows.
- Installing the VPN helper from Settings while connected is refused, because it would end the connection.
- FortiConnect no longer depends on which `whoami` comes first on the PATH when it installs the helper.

## Unsigned builds

On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On macOS, right-click the app and
choose **Open** the first time; macOS copies announce updates instead of installing them.
