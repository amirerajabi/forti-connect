Fixes SSL-VPN connections to FortiGates that use their own certificate on Windows.

FortiConnect 0.1.0 updates itself to this version (Settings → Updates).

## Downloads

- Windows: `FortiConnect-Setup-0.1.1.exe`
- macOS (Apple silicon): `FortiConnect-0.1.1-mac-arm64.dmg`
- Linux: `FortiConnect-0.1.1-x86_64.AppImage`

## Fixes

- **SSL-VPN no longer waits 60 seconds and fails when the FortiGate has a self-signed certificate.** OpenConnect's
  question about the certificate never reached FortiConnect on Windows. FortiConnect now checks the certificate itself
  before connecting, shows its fingerprint and asks whether to trust it, and remembers your answer. If the certificate
  changes later, FortiConnect warns you instead of connecting.
- **SSL-VPN connects straight to the FortiGate**, like FortiClient, instead of through a proxy set in `HTTPS_PROXY`
  (such as another VPN app's local proxy), which would have dropped the VPN whenever that app disconnected.

## Unsigned builds

On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On macOS, right-click the app and
choose **Open** the first time; macOS copies announce updates instead of installing them.
