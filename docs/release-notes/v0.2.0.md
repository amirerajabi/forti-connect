SSL-VPN on Windows without running FortiConnect as administrator.

FortiConnect 0.1.x updates itself to this version (Settings → Updates).

## Downloads

- Windows: `FortiConnect-Setup-0.2.0.exe`
- macOS (Apple silicon): `FortiConnect-0.2.0-mac-arm64.dmg`
- Linux: `FortiConnect-0.2.0-x86_64.AppImage`

## New

- **The FortiConnect VPN helper (Windows).** Windows only lets administrators create the network adapter a VPN needs.
  Like FortiClient's own service, FortiConnect can now install a small helper, once, with one administrator prompt:
  Home → **Install the VPN helper**, or Settings → VPN programs. After that FortiConnect runs as a normal user and the
  helper starts OpenConnect for it.
  - It runs from `C:\Program Files\FortiConnect Helper`, which only administrators can change, and starts with Windows.
  - Only your Windows account can talk to it, and it only starts the OpenConnect installed under Program Files.
  - Your VPN ends when FortiConnect disconnects or quits.
  - Settings → VPN programs can remove it again. "Restart as administrator" still works without the helper.

## Fixes

- The log no longer shows OpenConnect's "Server certificate verify failed" as an error when the certificate you
  trusted is accepted right after it.

## Unsigned builds

On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On macOS, right-click the app and
choose **Open** the first time; macOS copies announce updates instead of installing them.
