A first look at IPsec IKEv2 on Windows the way FortiClient does it: FortiConnect can now log in. Carrying traffic over
IPsec comes next.

FortiConnect 0.3.x updates itself to this version (Settings → Updates).

## Downloads

- Windows: `FortiConnect-Setup-0.4.0.exe` (includes OpenConnect)
- macOS (Apple silicon): `FortiConnect-0.4.0-mac-arm64.dmg`
- Linux: `FortiConnect-0.4.0-x86_64.AppImage`

## New

- **IPsec IKEv2 login on Windows (step 1 of 3).** FortiGate dial-up tunnels made for FortiClient (IKEv2, pre-shared
  key, user name and password) cannot be used with Windows' own VPN client, so FortiConnect now has its own IPsec
  engine. For an IPsec profile with **IKEv2 + EAP**, Connect logs in to the FortiGate, shows "the login worked (VPN
  address …)" and the details in the Log page, then signs out again. Using the tunnel for traffic is the next step;
  until then, use SSL-VPN where the FortiGate offers it.
- The profile form asks for the **pre-shared key** and the **local ID** (FortiClient's "Local ID") for IKEv2 profiles
  as well.

## Try it

Add an IPsec profile: gateway, user name and password, **IKEv2 + EAP**, the pre-shared key and the local ID from your
FortiClient profile. Press Connect, then open the Log page: it shows each step of the login.
